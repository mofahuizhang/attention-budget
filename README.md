## 三 七族之所从出

原语只有一对——不确定性（熵 `H`）／确定性（互信息 `I`）。约束不是原语，是原语对的**第一派生**，由「赋价」（转换必付代价）与「共享」（多主体须经共享结构）合成；「层级」属前提，不入合成式。

次序四步：**原语对 ⇒ 次生原语（约束）⇒ 概念体系 ⇒ 字典**。

七族是**同一条约束在七个机制面上的展开**——截断／格式／取舍／分配／存调／配平／反应。故七族体例同一、命题格式同一、证伪条件同一，可以并读；而各族凡例皆声明「自成一卷，不引用其他著作」，故也可单读。

> **关于「约束」二字。**它留在书名与正文里，作机制的称名；系列名取「**注意力预算**」——预算本身已含约束之义（有限、可分配、不可跨期结转），不必再冠一次。故系列称 Attention Budget，族名各带其机制面。

## 五 四域的口径

| 域 | 名 | 原生注意力的地位 | 主体 |
|:--:|---|---|---|---|
| NS | 自然人域 | **有本体**——可作本体计量者 | 个人 |
| HS | 人类社会域 | **汇集**——法人组织无本体，其「注意力」是成员本体经制度汇集而成的代理量 | 法人组织、社会整体 |
| LS | 生命域 | **层次递变**——从无神经系统到有神经系统，含「无」的极点 | 个体、细胞、种群、物种、生态系统 |
| IS | 机制域 | **无本体，其机制为人所造** | 人造系统与基础学科的对象 |

四字记法：**有本体——自然人；汇集——人类社会；递变——生命；人造机制——机制域。**

## 六 「论」是文体

七名以「论」收尾，取《文心雕龙·论说》的文体义。故《偏置约束论》读作「关于偏置的论」。

书中命题逐条附证伪条件与成立程度，凡未标定者明标未标定，凡不能设想出反例者不入卷。
